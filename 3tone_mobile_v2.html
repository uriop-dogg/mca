Three-tone Front / Back / 3D State Viewer

表空間（A, B, C の色相分布と重心）
裏空間（差音・補完音6成分の色相分布と重心）
3D 合成空間: 表平面を XY 平面、裏平面を XZ 平面に直交配置し、Front ベクトル F=(Re(w_front), Im(w_front), 0)、Back ベクトル B=(Re(w_back), 0, Im(w_back)) を合成。現在点 R=F+B と、m 範囲全体の軌跡を表示。
3D 操作: キャンバス上でドラッグすると視点回転、ホイールで拡大縮小、ダブルクリックで視点を初期化します。
